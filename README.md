# 即变

即变是一个面向微信小程序方向的 AI 人物玩法生成产品。当前仓库已包含产品文档、Pencil 设计稿，以及一个原生微信小程序 MVP 骨架。

## 当前工程

- `miniprogram/`：微信小程序 C 端 MVP，包含首页、玩法列表、上传生成、结果页。
- `project.config.json`：微信开发者工具项目配置，当前使用 `touristappid`，便于本地预览。
- `PRODUCT.md`：项目级产品上下文，供后续设计和工程实现保持一致。
- `docs/`：产品定位、命名和 MVP 思路。
- `Design/`：设计规范、Pencil 设计稿和图片素材。

## 本地开发

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择 `C:/code/my/jibian`。
4. AppID 可先使用测试号或当前配置里的 `touristappid`。
5. 导入后编译，默认进入 `pages/home/index`。

## 当前可跑流程

1. 首页点击「开始即变」。
2. 进入玩法列表并选择一个模板。
3. 在上传页选择本地图片。
4. 点击「开始生成」，使用本地进度条模拟生成。
5. 进入结果页，展示 mock 生成结果。

## CLI 说明

微信开发者工具已安装在：

```powershell
C:/Program Files (x86)/Tencent/微信web开发者工具
```

旧 CLI 入口为：

```powershell
& "C:/Program Files (x86)/Tencent/微信web开发者工具/cli.bat" open --project "C:/code/my/jibian" --lang zh
```

如果 CLI 提示服务端口关闭，需要在微信开发者工具中打开：

```text
设置 -> 安全设置 -> 服务端口
```

打开后可以继续使用 CLI 做打开项目、预览、上传等操作。没有打开服务端口时，直接用 GUI 导入项目即可。
