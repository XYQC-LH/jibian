# 即变 Prompt 撰写标准

## 1. 项目背景

即变是一个面向微信小程序的 AI 图像转换产品，当前以人物玩法为核心。用户上传一张图片，选择一个平台预设模板，系统使用模板背后的生成提示词驱动图片编辑或生成，输出一张可以保存、分享、发布的成品图。

产品的核心资产不是模板标题、页面分类或营销文案，而是每个模板背后的 `Template.prompt`。Prompt 决定结果图是否保留图片中主要主体的可识别特征、是否符合社交平台审美、是否有发布价值、是否稳定可控。后续任何 agent 参与模板生产时，核心任务都是撰写可直接写入后台 `Template.prompt` 字段的生成提示词。

## 2. 当前共识

Prompt 只服务生成结果，不承担前台营销字段职责。模板标题、模板分类、主标题、副标题、emoji、用途说明不需要在 Prompt 资产输出中单独列出，除非用户明确要求生成这些字段。

Prompt 需要把使用场景自然融入生成指令。例如可以写“画面适合作为微信头像”“适合朋友圈发布”“像小红书封面人物图”，但不要单独输出“用途：朋友圈”。Prompt 应该像一份视觉生成规格，而不是运营卖点、灵感短句或后台分类说明。

即变第一阶段以人物图片结果为核心，优先服务头像、社交展示、人像写真、风格化人物、角色化人物、朋友圈出片、小红书封面、轻商务形象等结果。但 Prompt 不要把输入图片绝对锁死为人物；如果用户上传宠物、物品或其他主体，Prompt 也要能围绕该主体完成风格转换，并保留主体的关键识别特征。不要把通用电商商品图、建筑空间、Logo、纯海报排版、产品 Mockup 当成即变核心 Prompt 方向。

## 3. 输出格式

当用户要求撰写模板 Prompt 时，默认只输出 Prompt 正文。不要附带以下字段：

- 模板标题
- 模板分类
- 分类主标题
- 分类副标题
- emoji
- 用途
- 风险等级
- 价格
- 输出比例
- 解释说明

单条 Prompt 使用完整中文段落即可，长度控制在 180-500 中文字符。批量输出时，每条只保留序号和 Prompt 正文，避免把运营字段混进生成字段。

推荐输出形态：

```text
1. 将这张图片转换为：……保留图中主要主体的核心识别特征；如果主体是人物，保留真实五官结构、脸型、年龄段和发型轮廓……
```

不推荐输出形态：

```text
模板标题：清冷胶片街拍
分类：今日出片
副标题：📷 普通自拍，变成能发朋友圈的照片
用途：朋友圈、小红书
Prompt：……
```

## 4. Prompt 必须包含的内容

每条 Prompt 都要覆盖以下信息，但不需要机械分段。内容应自然融合成一段或两段生成指令。

- `主体一致性`：保留图中主要主体的核心识别特征。如果主体是人物，保留真实五官结构、脸型、年龄段、发型轮廓和主要身份特征；如果主体是宠物、物品或其他对象，保留类别、外形轮廓、颜色、材质和关键细节。
- `结果目标`：明确最终要生成什么效果图，例如头像、街拍、胶片写真、古风角色、赛博人物、小红书封面、宠物氛围照或主体风格图。
- `构图镜头`：说明近景、半身、七分身、全身、头像裁切、正面、侧身、中心构图、主体留白等。
- `妆造服饰`：当主体是人物时定义服装、发型、妆容、配饰方向；当主体不是人物时，改为定义主体装饰、环境关系、质感变化和呈现方式。
- `场景环境`：定义背景、空间、地点、季节、时间、故事氛围或画面关系。
- `光线色彩`：定义自然光、夕阳、棚拍、柔光、霓虹、低饱和、暖色、冷灰、胶片颗粒等。
- `视觉质感`：定义写实摄影、胶片、电影感、3D、动漫、国风、水彩、C4D 等结果质感。
- `社交可用性`：把使用场景融入生成目标，例如适合头像、朋友圈、小红书、社交展示面或封面人物图。
- `负向约束`：明确避免崩坏、违规、擦边、过度 AI 感和不稳定输出。

## 5. 统一负向约束

每条 Prompt 都必须包含必要的负向约束。负向约束可以根据模板风格略微调整，但核心边界保持一致。

标准负向约束：

```text
不要改变图中主要主体的身份、类别和关键识别特征。如果主体是人物，不要生成明星脸，不要夸张改变五官，不要过度磨皮，不要暴露或擦边服装；如果主体是宠物、物品或其他对象，不要改成无关品类或丢失原有外形特征。不要出现文字、水印、logo、畸形手指、扭曲五官、额外主体、重复身体、低清晰度、脏乱背景或明显 AI 感。
```

当模板涉及职业、旅行、节日或特殊场景时，要额外避免制造真实证明含义。例如轻商务形象不能写成证件照、职业资质照；旅行场景不能暗示真实到访证明；婚纱或纪念类场景不能暗示真实事件伪造。

## 6. 风格细化标准

Prompt 不能只写“生成高级感照片”“生成小红书风格”。必须把风格拆成可被模型执行的视觉条件。

弱 Prompt：

```text
把用户照片变成高级感小红书写真。
```

合格 Prompt：

```text
将这张图片转换为：小红书风格的清透生活方式写真。保留图中主要主体的核心识别特征；如果主体是人物，保留真实五官结构、脸型、年龄段和发型轮廓。主体位于画面中心，呈现自然、干净、轻盈的生活方式状态，背景为有柔和窗光的咖啡馆或白色家居空间。整体色调低饱和、明亮、带轻微胶片颗粒，像真实摄影师拍摄的可发布朋友圈成片。不要改变主体身份、类别和关键识别特征，不要生成明星脸，不要过度磨皮，不要出现文字、水印、畸形手指、额外主体或明显 AI 感。
```

## 7. 可用方向

即变 Prompt 优先围绕以下方向生产：

- `头像焕新`：微信头像、小红书头像、氛围头像、动漫头像、轻商务头像。
- `今日出片`：城市街拍、胶片写真、咖啡馆生活照、朋友圈成片、旅行感照片。
- `变美营业`：更上镜、更清透、更有妆造和光线质感的人像或主体照片。
- `小红书感`：封面人物图、网感照片、低饱和氛围图、生活方式图片。
- `角色入戏`：古风角色、赛博角色、二次元角色、游戏感人物、幻想人物。
- `朋友圈大片`：街拍、节日、旅行、雪景、海边、城市夜景等可发布场景。
- `轻商务形象`：自然职业形象、个人展示面、头像和简介页照片，不做证件照表达。

## 8. 禁止方向

Prompt 不得引导以下结果：

- 明星脸、名人脸、公众人物模仿。
- 强换脸、真实身份替换、无痕替换他人。
- 未成年人相关人物生成模板。
- 情色、擦边、暴露、性暗示。
- 证件照、学历证明、职业资质、医疗、法律、金融等高信任用途伪造。
- 政治、宗教、灾害、犯罪、冲突等高风险事件场景。
- 多人复杂合成、视频生成、自由 Prompt 生图。
- 与上传主体无关的纯商品图、建筑空间、Logo、纯文字海报、产品 Mockup 等非社交展示结果型模板。

## 9. 撰写流程

撰写 Prompt 前先判断模板是否属于社交展示型图像转换模板。人物是即变当前最高频主体，但 Prompt 必须对宠物、物品或其他主体保持可执行性，不能因为输入不是人就失效。

撰写时按以下顺序组织内容：

1. 固定使用 `将这张图片转换为：` 作为起手式。
2. 定义最终结果类型和社交使用场景。
3. 写清主体构图、姿态、表情或展示角度，以及镜头语言。
4. 写清人物妆造/服饰，或非人物主体的装饰、质感、背景关系，再补充光线和色彩。
5. 写清视觉质感和画面完成度。
6. 补充负向约束。

默认使用中文提示词。语言要具体、可执行、视觉化，避免空泛形容词堆叠。可以使用“像真实摄影师拍摄”“可发布朋友圈成片”“适合微信头像裁切”这类结果导向描述。

## 10. 标准模板骨架

```text
将这张图片转换为：[结果类型]。保留图中主要主体的核心识别特征；如果主体是人物，保留真实五官结构、脸型、年龄段、发型轮廓和主要身份特征；如果主体是宠物、物品或其他对象，保留类别、外形轮廓、颜色、材质和关键细节。主体以[构图/景别]呈现，[表情/姿态/展示角度]自然，[妆造/服饰/装饰/质感]符合[风格方向]。背景为[场景环境]，使用[光线]和[色彩]，整体呈现[视觉质感]，像[真实场景/社交平台]中可以直接保存和发布的成片。不要改变主体身份、类别和关键识别特征，不要生成明星脸，不要过度磨皮，不要暴露或擦边服装，不要出现文字、水印、logo、畸形手指、扭曲五官、额外主体、重复身体、低清晰度或明显 AI 感。
```

## 11. 示例 Prompt

```text
将这张图片转换为：清冷胶片质感的城市街拍照片。保留图中主要主体的核心识别特征；如果主体是人物，保留真实五官结构、脸型、年龄段、发型轮廓和主要身份特征。主体以半身、七分身或完整主体构图出现在画面中心，状态自然放松，像真实摄影师在傍晚街头抓拍的生活方式照片。背景为有层次的城市街景、玻璃橱窗或湿润街道路面，使用柔和自然光和轻微胶片颗粒，整体色调偏冷灰、低饱和、干净高级，适合朋友圈和小红书发布。不要改变主体身份、类别和关键识别特征，不要生成明星脸，不要过度磨皮，不要夸张妆容，不要暴露或擦边服装，不要出现文字、水印、畸形手指、扭曲五官、额外主体、重复身体、低清晰度或明显 AI 感。
```

```text
将这张图片转换为：适合微信头像使用的清透氛围头像。保留图中主要主体的核心识别特征；如果主体是人物，保留真实五官结构、脸型、年龄段、发型轮廓和主要身份特征；如果主体是宠物或其他对象，保留原有类别、外形轮廓、毛色或材质细节。主体以近景头像式构图呈现，主体清晰，背景简洁柔和不抢主体。整体使用柔和窗光、低饱和色彩和细腻质感，像真实拍摄后的精修头像，适合社交平台展示。不要改变主体身份、类别和关键识别特征，不要生成明星脸，不要过度磨皮，不要遮挡主体关键特征，不要暴露或擦边服装，不要出现文字、水印、logo、畸形五官、额外主体、低清晰度或明显 AI 感。
```

## 12. 交付判断

一条合格 Prompt 应该让另一个 agent 或工程系统无需追问即可直接写入 `Template.prompt`。如果 Prompt 删除主体一致性后仍然能成立，说明它太像普通生图提示词；如果 Prompt 删除社交使用场景后仍然没有损失，说明它没有体现即变的产品价值；如果 Prompt 只有风格词没有镜头、场景、光线和负向约束，说明它还不能作为上线模板资产。
