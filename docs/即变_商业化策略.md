# 即变商业化策略

更新日期：2026-07-29

## 1. 商业化结论

即变第一期商业化只做积分充值和按模板消耗。用户在充值页购买积分，生成模板时按模板价格扣除积分；会员订阅不进入第一期用户端、后台配置和计费逻辑。

内部价值锚点定义为 `1 元人民币 = 10 积分`。该锚点只用于团队计算售价、赠送比例、毛利和消耗成本，不在用户端展示，也不在营销文案中表达为固定兑换比例。

## 2. 用户侧形态

用户侧只展示「积分充值」入口、余额、充值档位、到账积分和生成消耗。首页模板卡、模板详情页和生成确认区域展示本次模板需要消耗的积分，让用户在生成前明确知道余额是否足够。

用户余额不足时，系统引导进入积分充值页。充值成功后，系统返回原生成链路，并保持用户已选择的模板、上传图片和生成参数，用户可以继续点击生成。

第一期入口文案统一围绕积分，不使用会员订阅表达。我的页入口使用「充值积分」或「积分充值」，充值页标题使用「积分充值」，按钮使用「立即充值」。

## 3. 充值档位

充值档位固定为 6 个价格档。用户端卡片展示「支付金额」「实际到账积分」和营销角标，营销角标只表达赠送力度，不展示内部兑换公式。

`¥299` 档位赠送率上限固定为 20%，到账积分固定为 3588。运营侧不得通过临时活动把该档位实际到账提升到 3588 以上，除非同步调整模板消耗价格和毛利测算。

## 4. 模板消耗规则

模板价格以积分为唯一消耗单位。第一期最低模板价格为 `8 积分 / 次`，常规模板按结果质量、生成稳定性和内容稀缺度设置更高消耗。 

模板价格分层如下：

- 基础模板：`8-12 积分 / 次`，用于普通头像、轻风格、低成本玩法。
- 常规模板：`15-25 积分 / 次`，用于主推头像、写真、角色和场景模板。
- 高质量模板：`30-60 积分 / 次`，用于高质量写真、复杂角色、强场景迁移和高成本模型链路。

后台每个模板必须配置 `points_cost` 字段。用户端生成前读取该字段展示本次消耗，后端创建生成任务时再次读取服务端配置并以服务端价格为准，避免前端价格被篡改。
 
## 5. 成本与毛利底线 

当前单次生成成功的上游成本区间为 `¥0.02-¥0.1`。按最低模板 `8 积分 / 次` 计算，最大充值档下单次有效收入约为 `¥0.67`，扣除上游成本后的单次毛利约为 `¥0.57-¥0.65`。

第一期定价目标是保留足够的利润安全垫，同时允许用户通过大额充值获得更划算的单位价格。运营调整充值赠送或模板价格时，必须先计算最低模板在最大充值档下的单次有效收入，不能让低价模板长期低于成本安全线。

毛利测算公式：

```text
单次有效收入 = 支付金额 / 到账积分 * 模板消耗积分
单次毛利 = 单次有效收入 - 上游生成成本 - 支付通道成本 - 运营补贴成本
```
