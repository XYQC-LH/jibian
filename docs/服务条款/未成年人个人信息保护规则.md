本规则是《即变隐私政策》的组成部分，专门说明我们如何保护未成年人个人信息。未成年人及其监护人使用即变前，请仔细阅读本规则。

## 1. 适用对象

本规则适用于未满十八周岁的未成年人使用即变服务的相关个人信息处理活动。

即变不主动面向不满十四周岁的儿童提供服务。如果您是不满十四周岁的未成年人，请在父母或其他监护人同意和指导下使用本服务。我们处理不满十四周岁未成年人的个人信息时，将依法取得监护人同意并采取更严格的保护措施。

## 2. 监护人同意和指导

未成年人使用即变，应在监护人同意和指导下进行。未成年人进行以下操作前，应取得监护人同意：

1. 上传本人或他人照片。
2. 使用 AI 生成人物图片。
3. 保存、分享或公开发布生成结果。
4. 购买积分、高清下载、去水印、多次重生成等付费权益。
5. 提交投诉、反馈、客服沟通或注销账号申请。

监护人应帮助未成年人理解 AI 生成图片可能存在失真、误导、传播风险和隐私风险。

## 3. 我们可能处理的未成年人信息

在未成年人主动使用相关功能时，我们可能处理以下信息：

| 信息类型 | 使用目的 |
| --- | --- |
| 微信登录凭证、OpenID | 识别账号、记录权益和任务 |
| 上传照片、照片中的人像和图像特征 | 按用户选择的模板生成图片 |
| 生成结果图、任务 ID、任务状态 | 展示结果、保存下载、售后处理 |
| 支付订单、退款记录 | 权益发放、退款、未成年人消费处理 |
| 客服沟通、投诉举报记录 | 处理问题、保护权益、履行法定义务 |

未成年人上传的人像照片、面部图像、可识别个人身份的照片内容，可能属于敏感个人信息。我们会在必要范围内处理，并采取加密传输、访问控制、最短必要保存期限等措施。

## 4. 未成年人禁止或限制内容

为保护未成年人身心健康和合法权益，即变禁止或限制以下内容：

1. 上传、生成或传播未成年人色情低俗、暴露、性暗示、诱导打赏或不适宜展示的内容。
2. 上传他人未成年人照片，除非已经取得其监护人明确授权。
3. 使用未成年人照片进行恶搞、羞辱、霸凌、诽谤、冒充、诱导或商业利用。
4. 生成可能被误认为真实身份、真实事件、真实经历、证件、证明材料的图片。
5. 将未成年人生成结果用于违法违规、侵权、欺诈或其他高风险场景。

如果系统识别或我们判断内容可能涉及未成年人高风险场景，我们可能拒绝生成、限制展示、删除内容、进入人工复核或采取其他保护措施。

## 5. 付费和退款保护

未成年人购买积分、高清下载、去水印、多次重生成或其他付费权益，应取得监护人同意。

监护人如认为未成年人未经同意进行了不当消费，可以通过客服邮箱 825175944@qq.com 或客服 QQ 825175944 联系我们。请提供账号信息、订单信息、监护关系证明以及具体情况说明。我们会依法依规核实并处理。

## 6. 信息保存和删除

未成年人个人信息的保存期限遵循《即变隐私政策》中的最短必要原则。默认规则如下：

| 信息类型 | 默认保存期限 |
| --- | --- |
| 已上传原始照片 | 7 天 |
| 生成结果图 | 30 天 |
| 失败任务及返还记录 | 180 天 |
| 订单、支付、退款记录 | 至少 3 年，法律法规另有要求的从其规定 |
| 客服和投诉记录 | 180 天，存在争议或监管要求的可延长 |

监护人可以联系我们请求查询、更正、删除未成年人个人信息，撤回同意或注销账号。为保护未成年人权益，我们可能需要验证监护关系和身份信息。

## 7. 监护人权利

监护人可以依法代未成年人行使以下权利：

1. 查询、更正未成年人的个人信息。
2. 删除上传照片、生成结果或相关记录。
3. 撤回个人信息处理同意。
4. 申请注销账号。
5. 申请处理未成年人不当消费。
6. 投诉举报涉及未成年人的不当内容或侵权行为。
