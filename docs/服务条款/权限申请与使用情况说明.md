## 3. 各权限的具体说明

### 3.1 选中的照片或视频信息

当您点击上传、从相册选择图片时，我们会获取您主动选择的照片。该照片用于根据您选择的模板生成对应 AI 人物图片、进行内容安全审核、展示任务进度和结果。

如您不授权或不选择照片，将无法使用上传生成相关功能，但不影响您浏览模板。

### 3.2 摄像头

当您选择拍摄照片时，我们会调用摄像头能力。拍摄的照片用于 AI 生成输入、内容安全审核和结果展示。

如您拒绝摄像头权限，可以改用从相册选择照片的方式。

### 3.3 相册写入

当您点击保存结果时，我们会申请相册写入能力，用于将生成图片保存到您的本地相册。

如您拒绝相册写入权限，将无法直接保存到本地相册，但仍可在小程序内查看结果（具体以页面功能为准）。

### 3.4 微信登录凭证和 OpenID

当您使用生成、权益、订单、退款、客服等需要识别账号的功能时，我们可能通过微信登录能力获取登录凭证，并生成或使用 OpenID 等账号标识。

这些信息用于记录免费次数、积分余额、生成任务、订单和售后处理，不用于超出服务目的的身份识别。

### 3.5 微信支付相关信息

当您购买积分、高清下载或其他权益时，支付由微信支付等依法接入的支付服务提供方完成。我们会处理订单号、商品名称、价格、支付状态、交易流水号、退款状态等必要信息。

我们不会收集您的银行卡号、支付密码等完整金融账户敏感信息。

### 3.6 订阅消息

如果后续启用生成完成提醒、退款进度提醒或重要服务状态提醒，我们会在您主动订阅后发送相关消息。您可以通过微信设置或小程序入口管理订阅状态。

### 3.7 设备信息和日志信息

为保障服务稳定、安全和反作弊，我们可能处理设备型号、操作系统、小程序版本、网络状态、错误日志、访问时间、IP 地址、接口请求日志等基础信息。

这些信息主要用于故障排查、安全风控、内容安全审计和服务优化。

## 4. 如何管理权限

您可以通过以下方式管理权限：

1. 在微信小程序授权弹窗中选择同意或拒绝。
2. 在微信的小程序设置中查看和管理授权状态。
3. 在设备系统设置中关闭相机、相册等系统权限。
4. 通过客服邮箱或客服 QQ 联系我们，申请查询、删除、撤回授权或注销账号。

关闭权限后，您可能需要重新授权才能继续使用对应功能。
